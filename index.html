OpenStreetMap Kudla Contributor Guide

How to add missing everyday utilities and correct local details

1 Launch Web Editor

Open OSM's iD Editor centered on Mangalore. Log in with Google/GitHub/email.

2 Drop a Point

Click "Point" on the top toolbar and position it right on the shop or amenity.

3 Tag Local Details

Add phone number, opening hours, address, and Kannada/Tulu names (name:kn, name:tcy).

Essential Tags Reference for Kudla Utilities

Category Primary OSM Tag Examples & Recommendations
🔧 Hardware & Supplies shop=hardware / paint / electrical Pipes, electrical wires, tools, tiles
⚙️ Repairs & Craft shop=electronics_repair / bicycle_repair Mobile screen repair, shoe repair (craft=shoemaker)
📚 Stationery & Xerox shop=stationery / copyshop Photocopy, spiral binding, college supplies
💊 Pharmacies amenity=pharmacy Add opening_hours=24/7 if open round the clock
🚻 Public Toilets amenity=toilets Add fee=yes/no and wheelchair=yes/no
💧 Drinking Water amenity=drinking_water Free public RO water kiosks or public park taps
🚌 Bus Stops highway=bus_stop Add stage name and route info
✍️ Local Language Names name:kn=* / name:tcy=* Kannada and Tulu language place names
