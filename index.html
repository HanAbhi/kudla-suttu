Improve Kudla on OpenStreetMap

Help make Mangalore's everyday utility directory accurate for everyone

1
Open iD Web Editor

Launch OpenStreetMap's built-in editor centered on Mangalore. Log in with Google/GitHub/email.

2
Add a Point

Click "Point" on the top toolbar and click on the building or shop location.

3
Tag Essential Details

Add phone number, opening hours, address, and local language tags: name:kn (Kannada) and name:tcy (Tulu).
